# PG30ParthoGhosh_Unity_A2

Ball x is a platformer game where as a Ball you need to collect pickups in time. If timer runs out or you fall off the level, you die.

If you reach to big flag, you win.

Collect as many pickups to score big.


## How to play?

Use WASD or Directions to control the ball. 
Use mouse to control the camera.
Use spacebar to jump.
